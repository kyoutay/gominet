This is a sample blog post.

To add a new post, create a Markdown file in the `_posts` folder named `YYYY-MM-DD-your-post-title.md` with front matter at the top like this:

```yaml
---
title: "Your Post Title"
date: 2026-10-18
tags: [tag1, tag2]
---
```

Any tags you add in `tags: [...]` will automatically appear in the navigation links at the top of the site.
